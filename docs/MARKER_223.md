# Метка 223 — жесты холста, реплей и шкала iPad

**Тег:** `metka-223`  
**Desktop:** `desktop-v1.2.8` (Mac)  
**Откат:** `metka-222` / `desktop-v1.2.7`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- Логарифм не срывается в обычную шкалу из-за неположительного фитиля.
- Младший таймфрейм индикатора догружается на весь открытый график.
- Объём на графике цены больше не пересчитывает шкалу на каждом баре.
- Привязка к свече по Cmd или Control ставит точку у горизонталей, паттернов, позиции и профиля объёма.
- После перетаскивания ценовой шкалы график снова двигается, в том числе по цене.
- Перетаскивание шкалы дат меняет ширину свечей.
- Один щелчок колёсика не раздувает свечи, и следом узкое окно не возвращает крупный масштаб.
- На iPad полоска ценовой шкалы задаёт масштаб холста.
- Реплей принимает клик по свече: свечи правее скрываются, работают пуск и шаг.
