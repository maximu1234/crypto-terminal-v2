# Метка 211 — настройки индикаторов без пропадания свечей

**Тег:** `metka-211`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- Легенда индикаторов: текст на тиках обновляется in-place (клик по настройкам не срывается).
- Окно настроек индикатора: chrome-overlay, pin видимого диапазона, починен `onClose`.
- Ленивая история Терминала: сначала restore шкалы, потом RSI/индикаторы; не грузить, пока открыты настройки или идёт preserve.
- Backdrop настроек ослаблен (0.45 → 0.18), чтобы тонкие свечи на log-шкале не «пропадали».

## Версии

- Web: `v0.211`
- Desktop: `v1.1.96` (Mac + Windows)
