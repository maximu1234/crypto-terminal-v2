# Метка 63 — рисование, шаблоны, крест в zoom (июль 2026)

**Тег:** `metka-63`

## Что вошло

- **Прямоугольник:** цвет линии в настройках (шестерёнка), дефолты — фиолетовый `#a855f7`, заливка 15%, средняя линия выкл.; миграция `rectDefaultsVersion`.
- **Шаблоны рисования:** сохранение под существующим именем, кнопка «Сохранить», Enter в модалке, клик по списку — перезапись.
- **Позиция:** Enter применяет объём к пресетам после перетаскивания стопа (не только при фокусе в поле).
- **Скринер / Скрипт:** курсор-перекрестье в увеличенном окне графика (ПКМ); в виджетах без креста.

## Версии

- Web marker: `v0.63`
- Desktop app: `v1.0.56` (Mac `.dmg` → `desktop-v1.0.56`, Win `.exe` → `desktop-win-v1.0.56`)
