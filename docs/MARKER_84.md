# Метка 84 — Алго-бот: pt4 arm, orderLinkId, статус настроек (июль 2026)

**Тег:** `metka-84`

## Что вошло

### АлгоТрейдинг / бот (desktop-only)

- Фикс ложной отмены «pt4 уже заколот»: бар формирования pt4 больше не
  считается входом; вход только после `b4`.
- Фикс `OrderLinkedID is duplicate` после Quit/Stop: уникальный `orderLinkId`
  на каждую постановку триггера (и TP с nonce сессии).
- В окне Статус — вторая строка «Настройки»: `СЛ:50% (1$), ТП: 1к3`
  (для St2/St3 — уровни ТП через `/`).
