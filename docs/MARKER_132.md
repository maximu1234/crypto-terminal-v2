# Метка 132 — бот live-прогон + локальное время графиков + удалён Screener Live (август 2026)

**Тег:** `metka-132`

## Что вошло

- **Algo Bot:** обязательный прогон на закрытии бара (REST/память), не только WS;
  в логе — `прогон close …` и при незавершённом seed `N/M (ещё seed …)`.
- **Algo Bot:** kline WS watchdog по тишине свечей; подробные session-log решения
  по живым сетапам (в окне «баров до отмены»); без спама по мёртвым сетапам и без
  «повтор, уже в архиве».
- **Графики (все страницы):** ось времени / crosshair в локальной TZ браузера
  (данные свечей по-прежнему UTC).
- **Скрипт:** полностью удалён «Скринер live» (UI, лог, модуль, boot resume);
  основной авто-скан сохранён. Глубина поиска: опция **300 баров**.
