# Метка 87 — Алго панель Данные + безопасность desktop / флаги списка (июль 2026)

**Тег:** `metka-87`

## Что вошло

### АлгоТрейдинг — панель «Данные»

- «СЛ от X, %» перенесён в 4-ю колонку в одну строку со «Стоп-лосс ($)», выравнивание справа.
- «Паттерны Long/Short» вынесены над Стратегией 1 отдельным блоком (лёгкая подложка + разделитель).
- Колонки 1–3 резиновые по ширине; 4-я фиксированная.
- Скрыт вертикальный scrollbar панели (прокрутка колёсиком сохранена).

### АлгоТрейдинг — список монет

- Флаги списка (long/short/both/favorites) на странице Алго, не терминальные цвета.

### Чертёж позиции

- Метрики TP/SL % и RR в лог-шкале (`100 × |ln|`); объём $ по-прежнему от линейного СЛ %.

### Desktop / изоляция

- Gate торговых/алго IPC при remote UI / fallback на Vercel.
- Жёстче `orderLinkId` бота; PnL `tempPath` только во временной папке.
- Auth session через secret store; `supabase-env.js` снят с трекинга.
- Vercel: `/algo-trading` → скринер.
- Pattern 1-2 оригинал восстановлен (алго-копия отдельно).
- Win: popup трея вверх.
- Cloud: поле `source` у price alerts (+ migration SQL).
