# Метка 163 — RSI Flip: isolated на весь бот, не по тикеру

**Тег:** `metka-163`

## Что вошло

- **Боты → RSI Touch Flip:** один чекбокс «Изолированная маржа» рядом
  с долей баланса. Режим один на всю книгу (на Unified Bybit — на весь
  субаккаунт API-ключа).
- Чекбокс убран из панели Данные; live больше не читает маржу из строки
  тикера. Старые книги с isolated в prefs поднимают общую галочку.

Оригинал Pattern 1-2 не менялся.
