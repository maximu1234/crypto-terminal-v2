# Метка 59 — локальные флаги/рисунки, лёгкий alerts fallback, удаление BTC.D (июль 2026)

**Тег:** `metka-59`

## Что вошло

- Флаги больше не подтягиваются автоматически после логина и device pull.
- Рисунки полностью зафиксированы как локальные: отключены авто pull/push и device pull по рисункам.
- Для облачных алертов оставлен событийный sync; частые fallback-пуллы убраны, safety fallback переведён на 30 минут.
- Удалена страница `btc-d.html`, очищены ссылки на неё.
- В Терминале убран рынок `Индексы` из выпадающего фильтра справа.
- Согласованы версии ассетов и пересобран desktop bundle.
