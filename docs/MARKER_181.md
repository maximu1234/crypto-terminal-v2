# Метка 181 — MOEX read-only + замок объектов рисования

**Тег:** `metka-181`

> **ROLLBACK BASELINE** для инициативы chrome/chart perf
> (`docs/PERF_CHROME_CHART.md`). Пока идёт инициатива — тег и этот файл
> **не удалять**, даже если правило «оставить N…N-3» уже дальше.

## Что вошло

- **MOEX (только чтение):** биржа в Подключениях, списки/свечи на
  Скринере и Терминале через `/api/moex` и `js/exchanges/moex/*`;
  торговля/Вотчлист/Алерты/Дневник/Алго/Скрипт — заглушки при active=moex.
- **Рисование — замок:** в float-меню кнопка закрепления объекта
  (`shape.locked`); мультивыбор лочит/снимает замок со всех сразу;
  drag/resize заблокированы, стиль/удаление доступны.
- **Fix:** Save Template открывается с первого клика (убран битый
  `signal` при создании модалки шаблона).
