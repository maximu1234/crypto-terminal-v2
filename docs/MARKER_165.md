# Метка 165 — мультивыбор рисунков, Эллиотт, каналы, алерты в приложении

**Тег:** `metka-165`

## Что вошло

- **Мультивыбор рисунков как в TradingView:** ⌘/Ctrl + рамка, ⌘/Ctrl + клик,
  общее перемещение / удаление / стиль, ⌘/Ctrl + drag — клон группы.
- **Волны Эллиотта** и **уровни канала** (Fib Channel–стиль).
- **Алерты:** срабатывание в Telegram снова даёт звук и снимает линию в
  открытом приложении (realtime DELETE = fire; история событий тоже).
  Ручное снятие на worker — soft `deleted_at`, чтобы другое устройство не
  приняло удаление за fire.
- **Вотчлист:** живая цена по тикеру, не только kline.
- Прочее: прозрачность цвета рисунка с клавиатуры, синий флаг ТФ на вотчлисте,
  пресеты объёма по символу, снимок графика на Windows.

Оригинал Pattern 1-2 не менялся. Bybit/BingX — только bump `?v=` на общий
`alerts.js`.
