# Метка 141 — desktop-прокси и свечи Вотчлиста

**Тег:** `metka-141`

## Что вошло

- **Прокси в настройках .app:** SOCKS5/HTTP, логин/пароль, тест, вкл/выкл.
  Chromium ходит через локальный SOCKS-релей (удалённый SOCKS5 с RFC1929).
- **Сплит трафика Bybit:** свечи REST (`api.bybit.com` / `api.bytick.com`) —
  напрямую; тики `stream.bybit.com` и подписанный REST/WS — через SOCKS.
- **Вотчлист:** виджеты больше не ждут ~20 с: kline-гонки как на Терминале,
  первая страница свечей рисуется сразу.
- Линии позиции на графике Терминала не ждут медленный `getPosition` через SOCKS.

Оригинал Pattern 1-2 не менялся. Desktop-релиза нет.

## Версии

- Web marker: `v0.141`
- Multichart desktop app: без релиза (остаётся `v1.1.39`)
