# Метка 196 — плечо RSI Touch Flip и переход из Дневника

**Тег:** `metka-196`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- RSI Touch Flip: поле **Плечо** в настройках бота (по умолчанию 10x). Перед работой бот ставит его на все монеты книги; если биржа не даёт это значение, снижает до максимума по монете.
- Дневник → Терминал: график открывается на сохранённом таймфрейме и с обычным масштабом, без принудительного 1ч и зума в сделку.
- Стрелки этой сделки на Терминале золотые и крупнее остальных.
