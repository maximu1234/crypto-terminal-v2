# Метка 143 — Алго график, стакан bid/ask, desktop 1.1.41

**Тег:** `metka-143`

## Что вошло

- **АлгоТрейдинг:** без ботов график грузит ~5000 свечей (как Терминал).
  При любом боте аналитики после первой отрисовки догружает до ~10 000.
  Переключение тикеров без бота больше не ждёт 10 запросов.
- **Алго список:** чекбокс бота не обнуляет котировки, если рынок «Все».
- **Стакан:** best bid / best ask остаются подсвеченными на любом сжатии
  сетки (x2, x5, …). Пустое окно само возвращается к спреду.
- Оригинал Pattern 1-2 math/paint не менялся.

## Версии

- Web marker: `v0.143`
- Multichart desktop app: `v1.1.41`
