# Метка 78 — агент в меню при логине и легче стакан (июль 2026)

**Тег:** `metka-78`

## Что вошло

### Menu-bar agent (macOS)

- Закрытие окна при включённом tray → режим агента: окно уничтожается,
  stream и иконка в строке меню остаются; Dock скрыт.
- Feed PnL/позиций из main (`menu-bar-tray-feed.cjs`), без нагрузки renderer.
- **Настройки → Системные:** «Запускать агент при входе в систему» —
  LaunchAgent с `--agent` (на macOS 13+ `openAsHidden` не работает).
- При логине: только tray, без окна Multichart; окно — по клику на иконку.

### Scalping DOM — CPU

- Отрисовка стакана ограничена (~12.5 fps), пауза при `document.hidden`.
- Кэш оверлеев (~300 мс); патч строк вместо полной пересборки DOM,
  когда сетка цен не менялась.
