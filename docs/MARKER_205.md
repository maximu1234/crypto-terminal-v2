# Метка 205 — шапка вотчлиста и стакан

**Тег:** `metka-205`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- В виджетах Вотчлиста кнопки рисования и объёма не наезжают друг на друга. На узком виджете скрыты процент хода, число объёма и цены на кнопках покупки и продажи.
- Фигура, чей якорь уже на графике, не пропадает из-за отсечения по окну времени.
- Полосы объёма в стакане считаются по всей глубине книги, а не по видимым строкам. Прокрутка их не перескакивает.
- Ручной максимум полосы сохраняется отдельно для каждой монеты. Пустое поле — автомасштаб по всему стакану.
- Пока курсор над стаканом, прокрутка не возвращает спред в центр. Автоцентровка срабатывает после увода мыши.
