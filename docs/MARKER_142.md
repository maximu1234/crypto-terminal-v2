# Метка 142 — Early T3, стакан, секреты и desktop 1.1.40

**Тег:** `metka-142`

## Что вошло

- **Скрипт:** выбор индикатора скана — Паттерн 1-2 или 1-2 EARLY T3
  (настройки с Терминала). Оригинал Pattern 1-2 math/paint не менялся.
- **Алго:** отдельный бот 1-2 Early T3 — только алерты, без ордеров,
  Bybit linear. Не смешивается с Pattern 1-2. Галочка «АлгоТрейдинг»
  в Системе глушит resume бота и live-runtime.
- **Терминал / стакан:** горизонтальная линия и горизонтальный луч
  рисуются в стакане цветом с графика, всегда 2px.
- **PnL-карточка:** «Сохранить» открывает последнюю выбранную папку.
- **Секреты / IPC:** `apiSecret` не пишется в localStorage; LAN-токен —
  sessionStorage; CORS session-log без `*`; snapshot IPC за UI-gate;
  пароль прокси не отдаётся в renderer.

## Версии

- Web marker: `v0.142`
- Multichart desktop app: `v1.1.40`
