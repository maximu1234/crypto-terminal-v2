# Метка 96 — magic-link вход: очередь callback + статусы (июль 2026)

**Тег:** `metka-96`

## Что вошло

### Вход по ссылке из письма (desktop)

- Preload ставит `desktop:auth-callback` в очередь, если UI ещё не подписан (раньше callback терялся на boot Терминала).
- При обработке ссылки открывается Настройки → Синхронизация.
- Пошаговые жёлтые статусы: «Ссылка получена» → «Обрабатываем…» → «Сверяемся с базой…».
- После входа панель Telegram обновляется (зелёный «Chat ID сохранён…»).
- Убран неточный текст про синхронизацию избранного и рисунков.
- Форма входа в Синхронизации обновляется сразу после успешного magic-link.
