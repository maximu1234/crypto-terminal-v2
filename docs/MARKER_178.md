# Метка 178 — RSI Flip ghost, флаги, тикер Терминала

**Тег:** `metka-178`

## Что вошло

- **RSI Flip live:** перед сбросом «позиции нет» — confirm `getPosition`;
  блок повторного входа, пока RSI в зоне; пагинация `getPositions`
  (`desktop/trading` + `bot-app/trading`).
- **Доходность (Алго):** кривая по закрытым сделкам в USDT, точки на выходах.
- **Флаги избранного:** клик по флагу сразу помечает локальные данные
  unsynced — быстрый уход на Скринер больше не затирает флаг облаком.
- **Терминал:** не мигать `BTCUSDT.P` до загрузки списка — держим
  последний тикер биржи; ранняя подпись в шапке из `lastViewByExchange`.
