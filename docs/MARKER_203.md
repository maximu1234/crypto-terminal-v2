# Метка 203 — проигрывание графика на Терминале

**Тег:** `metka-203`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- На Терминале есть Replay: клик по свече скрывает всё правее неё, дальше шаг и воспроизведение открывают свечи по одной.
- Пока выбирается стартовая свеча, вертикальная линия курсора сплошная синяя.
- Масштаб графика не меняется ни при выборе свечи, ни во время проигрывания. Зум колесом сохраняется.
- Кнопка Replay стоит в верхней панели после «Сохранить PNG».
- Индикаторы, включая RSI, видят только уже открытые свечи. Живые ордера из этого режима не отправляются.
