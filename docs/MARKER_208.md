# Метка 208 — Volume на графике, цвет свечей, вход 1x

**Тег:** `metka-208`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- Volume рисуется внизу панели цены. Прозрачность столбцов настраивается, по умолчанию 0.72.
- В Системных два режима цвета свечей: красно-зелёные и монохром. Режим общий для всех графиков.
- RSI Touch Flip при плече 1x входит на 90% свободного баланса.
