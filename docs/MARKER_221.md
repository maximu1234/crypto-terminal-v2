# Метка 221 — проба холста и покой Терминала

**Тег:** `metka-221`  
**Откат:** `metka-220` / `desktop-v1.2.6`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- Терминал в покое меньше трогает график: тот же формат цены не вызывает `applyOptions`, тот же бар с теми же OHLC не считается изменением, живые свеча и RSI склеиваются, сдвиг шкалы не запускает цикл рисунков.
- Отдельная страница `canvas-bench.html` рисует свечи своим холстом: история один раз, тик — только последняя свеча. На ней же шкала, RSI, AO, MACD, объём, рисунки пробы, образцы заявок и PnL. Это не график Терминала.
- Desktop открывает эту страницу только по `DESKTOP_START_PATH=/canvas-bench.html` и не уводит её на сайт.

## Версии

- Web: `v0.221`
- Desktop: без нового релиза, остаётся `v1.2.6`
- Algo Bot: без изменений, `1.0.181`
