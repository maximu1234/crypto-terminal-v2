# Метка 218 — крупные заявки и стакан

**Тег:** `metka-218`  
**Откат:** `metka-217` / `desktop-v1.2.3`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- На скринере блок «Крупные заявки» берёт отдельный снимок 50 уровней по видимым монетам, раз в пару секунд. Полный стакан `orderbook.1000` остаётся только у открытой монеты.
- Виджет, ушедший с экрана, отпускает сокет свечей и экземпляр графика. Возврат собирает график из свечей, которые уже в памяти.
- Зум виджета больше не оставляет клетку пустой. Нижний индикатор (RSI, MACD или AO) дорисовывается вместе с графиком.
- Полоса заявок стоит внизу страницы, под номерами. Тикер белый и открывает эту монету на Терминале в таймфрейме, который там уже был. Сторона пишется Buy / Sell.
- Стакан Bybit идёт сокетом основного процесса, как свечи, и не крутит переподключения через SOCKS в окне.
