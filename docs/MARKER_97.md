**Тег:** `metka-97`

## Что вошло

### Терминал — история свечей

- Настройки → Системные: «Глубина истории (свечей)» 5000–15000 (дефолт 5000).
- Старт: ~5000 свечей; при сдвиге графика влево — догрузка до лимита.
- Видимая область: **2500** на всех ТФ.

### АлгоТрейдинг

- Видимая область тоже **2500**; загрузка ~10 000 без изменений.

### UI

- Убраны стрелки number-input и оранжевая/цветная focus-обводка (глобально + настройки).
- Поле активного объёма в шапке Терминала шире (как в попапе).
- Правило версий desktop: после `1.0.99` → `1.1.01` (не `1.0.100`).
