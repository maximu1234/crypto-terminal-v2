# Метка 88 — Глобальная статистика стратегий на всех тикерах (июль 2026)

**Тег:** `metka-88`

## Что вошло

### АлгоТрейдинг — панель «Данные» / аналитика

- После «Результаты поиска»: **Проверить на всех тикерах** · чекбокс реального
  подсчёта · Запустить / Стоп · статус.
- Три кнопки **Ст1 / Ст2 / Ст3** с итоговым `netUsd` по всему рынку.
- Клик по кнопке — попап: Лонг/Шорт (кол-во, %, $) + суммарная прибыль по сторонам.
- ТФ из 4-й колонки; один проход свечей считает все три стратегии.
- Чекбокс: вкл = реальный подсчёт, выкл = прямой.
- Правки вёрстки блока (статус перед Запустить, кнопки в одну строку).
