# Метка 232 — без пароля Связки ключей на Mac, 1.2.16

**Тег:** `metka-232`  
**Desktop:** `desktop-v1.2.16` (только Mac)  
**Откат:** `metka-231` / `desktop-v1.2.15`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- Mac больше не шифрует ключи через Связку ключей и не спрашивает пароль компьютера при запуске.
- Файлы, которые 1.2.15 уже успел зашифровать, один раз читаются и снова сохраняются обычным текстом.
- Windows по-прежнему шифрует ключи через DPAPI, без диалога.

## Версии

- Web: `v0.232`
- Desktop: `v1.2.16` (Mac, редакции f и m)
- Windows: без новой сборки
- Algo Bot: без новой сборки (`1.0.182`)
