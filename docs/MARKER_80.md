## Что вошло (состояние на момент метки)

### АлгоТрейдинг (desktop-only плагин)

- Страница `/algo-trading.html`, изоляция от оригинального Pattern 1-2
  (копии в `js/algo-trading/`).
- Три стратегии статистики + глобальные СЛ / таймаут баров.
- История графика до ~10 000 свечей; `MAX_HIST = 10000` только в алго-копии.
- Скан тикеров по винрейту (Лонг / Шорт / Лонг+Шорт), списки
  «Алго Лонг 5мин», «Алго Шорт 5мин», «Алго Лонг/Шорт 5мин».
- Правило `.cursor/rules/algo-trading.mdc`.

### Tray PnL privacy

- Main-process feed учитывает `pnlHidden`; глазик в popup трея;
  синхронизация с глазиком панели «Позиции».
