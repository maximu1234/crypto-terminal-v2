# Метка 169 — RSI Touch Flip: в бота зелёный Test, hardening подбора

**Тег:** `metka-169`

## Что вошло

- **Подбор RSI Touch Flip** ставит в поля и в бота максимум Обзора среди
  наборов с зелёным Test. Чемпион всего графика с красным Test остаётся
  в карточке, в колонку и ticker-store после reload не попадает.
- Нет свечей или некорректный ТФ RSI — ошибка в Обзоре, без тихого RSI
  с графика. `Infinity` профит-фактора переживает `localStorage`.
  Смена тикера во время сетки отменяет запись. СЛ цикла / Compound
  пересчитывают карточку подбора.
- Аналитика `none` больше не стопает live-бота с любой страницы.
  API key алго-профиля в renderer только при открытых настройках.
- Публичный `/health` воркера не форсит reload алертов и не отдаёт
  project ref / jwt role. Локальный BingX-прокси — только quote-пути.
  CI проверяет `.cjs`.

Оригинал индикатора Pattern 1-2 не менялся. Торговые модули Bybit/BingX
не затрагивались.
