# Метка 210 — UI терминала, RSI и EMA Shift

**Тег:** `metka-210`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- Вотчлист: виджеты сразу в нужном масштабе; осциллятор (RSI/MACD/AO) как в настройках шестерёнки.
- Терминал: включение Volume/индикаторов не сдвигает окно и не гасит свечи на несколько секунд.
- Верхнее меню чуть ниже по высоте.
- RSI: чекбокс «Линии цветом» (выше 50 — зелёный, ниже — красный).
- SuperTrend: «Сбросить в дефолт» (ATR 10, Factor 3).
- EMA Shift Ribbon: авто-строки Верхняя / Нижняя с подбором длины и сдвига по экстремумам.
