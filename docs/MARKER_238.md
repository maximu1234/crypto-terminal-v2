# Метка 238 — рисунки на перевёрнутой шкале, Mac и Windows 1.2.21

**Тег:** `metka-238`  
**Desktop:** `desktop-v1.2.21`, `desktop-win-v1.2.21`  
**Откат:** `metka-237` / `desktop-v1.2.20`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- На перевёрнутом графике клик и вертикальный зум по ценовой шкале больше не ставят рисунки прямо, пока зажата кнопка мыши. После отпускания они остаются на своих ценах.
- Зум шкалы держит под курсором ту цену, которая видна на перевёрнутом графике.
