**Тег:** `metka-82`

## Что вошло

### АлгоТрейдинг (desktop-only)

- Log-шкала SL/TP для St1–St3 (аналитика + бот); высота Position = farthest TP.
- История ~10k свечей: `MAX_HIST=10000` в алго-копии math; на графике
  Pattern 1-2 рисуется алго-копией (оригинал индикатора не трогали).
- Бот St1–St3: мультивыбор направлений (Лонг / Шорт / Лонг и Шорт) —
  каждый со своим списком; Избранные без изменений по смыслу.
- Статус бота: строка «Направление»; парсинг тикеров — дефолт 50% во всех
  трёх полях.
- UI: убрана подсказка панели «Данные»; без focus-ring на кнопках/селектах.
