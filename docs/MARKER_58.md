# Метка 58 — Header/settings/script stabilization (июль 2026)

**Тег:** `metka-58`

## Что вошло

- Унификация desktop-header (единая структура и навигация по страницам).
- Фиксы страницы `script`:
  - корректный фильтр направления (`long` / `short` / `both`);
  - синхронизация параметров поиска из toolbar перед запуском скана;
  - исправления фонового скана и отображения статуса.
- Возврат и стабилизация layout-иконок на странице `terminal`.
- Единое окно настроек и web-ограничения:
  - в web скрыты разделы `Подключения` и `Торговля`;
  - `BingX` в `Подключения` временно отключен (неактивный переключатель).
- Техническая синхронизация версий ассетов и desktop bundle.
