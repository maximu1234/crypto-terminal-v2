# Метка 95 — privacy баланса + имя биржи на Статистике (июль 2026)

**Тег:** `metka-95`

## Что вошло

### Глазик (скрытие PnL)

- **Подключения:** баланс USDT маскируется в `***`, когда глазик включён; обновляется при переключении.
- **Системный трей:** строка «Баланс USDT» тоже маскируется вместе с PnL позиций.

### Статистика

- В тексте страницы и сообщениях статуса/ошибок — имя **активной** биржи (Bybit / BingX), а не захардкоженный Bybit.
- Фикс: восстановлен экспорт `STATS_JOB_UPDATE_EVENT` после правки фона.
