# Метка 75 — BingX, дневник и модульная изоляция (июль 2026)

**Тег:** `metka-75`

## Что вошло

### Торговля BingX

- Исправлено изменение SL/TP без дублей и возврата линии к старой цене.
- Добавлены согласование stop-orders, pending amend state и защита от устаревших
  stream-снимков.
- Автоматические SL/TP после входа ставятся в фоне и не задерживают открытие
  позиции.
- Исправлена очистка mutex последовательных изменений стопа.
- Настройки, REST и stream BingX разнесены по отдельным адаптерам.

### Дневник BingX

- REST дневника вынесен в независимый `bingx-rest-diary.cjs`.
- Исправлены отсутствующие зависимости `peekRateLimitBlock` и
  `extractBingxList`; добавлена явная проверка bind-контракта.
- Page, period, detail, chart и cache дневника изолированы в модуле BingX.
- Исправлены загрузка периодов, исполнение длинных сделок, комиссии и маркеры.

### Архитектура и интерфейс

- Толстые shared trade-файлы заменены тонкими фасадами; бизнес-логика BingX
  находится только в `js/trade/bingx/**`.
- Продолжен split drawings: настройки и position drawing вынесены в модули.
- Сохраняется последний символ отдельно для каждой биржи.
- Удалены BTC dominance, неиспользуемые stubs и временные изображения.
- Добавлены тесты BingX stops, trading router, stream facade, drawings,
  terminal exchange symbol и desktop cloud auth callback.

## Изоляция

- Изменений торговой логики Bybit в метке нет.
- Trade, Script и Diary остаются доступны только в desktop-приложении.
- Mac- и Windows-адаптеры сохраняют отдельные платформенные границы.
