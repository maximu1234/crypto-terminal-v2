# Метка 222 — свой холст вместо Lightweight Charts

**Тег:** `metka-222`  
**Desktop:** `desktop-v1.2.7` / `desktop-win-v1.2.7`  
**Откат:** `metka-221` / `desktop-v1.2.6`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- Свечи Терминала, Скринера, Вотчлиста и Алго рисует свой холст. Lightweight Charts больше не строит эти графики.
- Ценовая шкала как в 4.1.3: обычный режим держит один шаг, логарифм пересчитывает шаг вниз по диапазону. Подписи шкалы стоят в одном столбце с цифрами плашки текущей цены.
- На линейном графике остаётся горизонтальная линия текущей цены.
- У виджетов и Zoom Скринера нет сетки. На плашке виджета снова есть цена и время до закрытия бара.
