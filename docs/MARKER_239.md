# Метка 239 — магнит и внешний вид, Mac и Windows 1.2.22

**Тег:** `metka-239`  
**Desktop:** `desktop-v1.2.22`, `desktop-win-v1.2.22`  
**Откат:** `metka-238` / `desktop-v1.2.21`

## Что вошло

- На Терминале пункт «Магнит» перед глазиком. Включённый магнит клеит опорные точки к свечам без Cmd. Зажатый Cmd по-прежнему клеит сам.
- В настройках шестерёнки пункт «Внешний вид»: цвета интерфейса и свечей, палитра у поля и возврат к исходным цветам. Хранится только в этом браузере.
