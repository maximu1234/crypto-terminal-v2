# Метка 152 — LAN RSI Flip старт/стоп, подбор по Обзору, desktop 1.1.51

**Тег:** `metka-152`

## Что вошло

- **LAN Multichart ↔ Algo Bot:** токен канала не затирается пустым полем и не
  ротируется при Save. Старт RSI Touch Flip по LAN отвечает сразу (seed в
  фоне), стоп не блокируется `commandBusy`. Вместе с стартом уходит книга и
  `balancePct`.
- **Подбор RSI Touch Flip:** победитель сетки — максимум чистой на всём
  графике (колонка Обзор). Train/Test только решают, включать ли тикер в бота.
  Просадка Test больше не вето: Test «зелёный» при плюсе, сделках и PF ≥ 1.
  «Подставить» работает без повторного прогона сетки.

Оригинал Pattern 1-2 не менялся.
