# Метка 99 — market reduce без flip, горизонтальная линия, хоткеи (июль 2026)

**Тег:** `metka-99`

## Что вошло

### Торговля — market buy/sell без переворота

- При встречной позиции зелёная/красная кнопка только уменьшает/закрывает её (`qty` capped).
- Избыток объёма не открывает противоположную сторону.
- Bybit: `reduceOnly` + `min(qty, size)`; BingX: close sides (`SELL`+`LONG` / `BUY`+`SHORT`).

### Рисунки — Горизонтальная линия

- Новый инструмент `hline`: одна точка, линия влево и вправо на весь график.
- Стиль и float-меню как у Horizontal Ray; дефолт цвет `#3b82f6`, толщина 1px.
- Тулбар: курсор → тренд → hline → hray → стрелка → …
- Иконки тулбара снова 50×70 (encode с проверкой размера).
