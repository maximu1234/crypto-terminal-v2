# Метка 195 — Volume Bubbles на Терминале

**Тег:** `metka-195`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- Индикатор **Volume Bubbles** на главном графике Терминала (SMA объёма × множитель, размер шара от ratio).
- Настройки: период SMA, множитель, мин. объём, масштаб размера, цвета long/short.
- Чекбокс **«Подписи объёма»** — шильда при наведении / клике (Покупка|Продажа, объём, ×к SMA).
- Клик по легенде слева открывает настройки.
- Math + unit-тесты: `js/indicators/volume-bubbles*.js`, `tests/volume-bubbles-math.test.mjs`.
