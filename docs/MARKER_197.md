# Метка 197 — имена тикеров, меню рисования и быстрый список Мосбиржи

**Тег:** `metka-197`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- На графике Терминала сверху слева полное имя тикера: Bybit, BingX (через каталог Bybit, где биржа сама не отдаёт название) и Мосбиржа (короткие имена ISS).
- Рисование: скрытие всех объектов, у прямоугольника отдельные горизонтальные и вертикальные стороны, у Фибоначчи один выключатель подписей, шаблон применяется ко всем выделенным фигурам того же типа. Левый клик по группе сразу берёт инструмент по умолчанию, правый открывает меню. Корзина удаляет с первого нажатия. У паттерна 1-2-1-2-3 отдельные типы линий.
- Меню рисования собраны в одну более плотную карточку.
- Список Мосбиржи на Терминале открывается из сохранённой копии. С биржи уходит один короткий запрос на борд, а не повтор одной и той же толстой страницы. Вкладки Акции / Валюта / ETF фильтруют уже загруженный список. ETF — фонды с борда акций.
