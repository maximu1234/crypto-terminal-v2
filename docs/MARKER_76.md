# Метка 76 — стакан для скальпинга и правые плашки шкалы (июль 2026)

**Тег:** `metka-76`

## Что вошло

### Стакан для скальпинга (desktop Terminal)

- Изолированный плагин `js/scalping-dom/`: WS depth Bybit/BingX, ladder UI,
  price scale (x1…x25), volume bars.
- Вкл/выкл чекбоксом в шапке Терминала перед лейаутами (не в шестерёнке).
- Автоцентровка с паузой при наведении мыши.
- Линии алертов (жёлтый пунктир), триггерных ордеров (сплошные green/red),
  подсветка и edge-линии SL/TP позиции.

### Правые плашки на ценовой шкале

- Цветные плашки цен для позиций (entry/SL/TP), ордеров и алертов на правой
  шкале основного графика.
- На панели RSI плашки trade/alert не рисуются (`includeExternalScaleLabels`).

## Изоляция

- Стакан монтируется только в desktop + страница Терминал.
- Trade / Script / Diary по-прежнему только desktop.
- Правки chart-overlay/orders зеркально для Bybit и BingX без общего policy-слоя.
