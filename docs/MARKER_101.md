# Метка 101 — логотип на скриншоте графика (июль 2026)

**Тег:** `metka-101`

## Что вошло

### Терминал — лого на скриншоте (desktop)

- Настройки → **Системные**: чекбокс «Ставить лого на скриншот» + **Загрузить PNG/JPG**.
- Файл в `userData`: оригинал PNG + ч/б ресайз (JPG/JPEG конвертируются в PNG).
- При Copy / Save PNG (если включено): полупрозрачный логотип поверх `#charts-stack-panes`.
- Размер ≈ 80% от высоты области / 5; позиция — слева сверху с отступом от угла; opacity `0.28`.
- Плашка тикера без изменений.
