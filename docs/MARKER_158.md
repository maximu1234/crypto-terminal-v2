# Метка 158 — scalping DOM: сжатый BBO, заливка позиции, первый заход BTC

**Тег:** `metka-158`

## Что вошло

- **Спред в стакане:** подсветка последней аск и последней бид текущего
  сжатия (x1…x25), две целые строки; без сплита из остатка чужой стороны
  в бакете.
- **Заливка открытой позиции:** от входа до своей линии спреда (шорт →
  last ask, лонг → last bid); чужая строка спреда не перекрывает заливку
  целиком.
- **SL / TP:** полупрозрачная заливка строки (красный / зелёный), без
  белой полосы и красной обводки.
- **Bybit DOM:** `orderbook.1000`; тик BTC снэпается (1/2/5×10ⁿ), чтобы
  первый заход на BTCUSDT.P не рисовал дырки; REST не затирает живой
  WS-снимок дельтами до snapshot.
- **Worker:** крупные WS-кадры как `ArrayBuffer`.

Оригинал Pattern 1-2 не менялся.
