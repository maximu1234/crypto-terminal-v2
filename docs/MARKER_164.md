# Метка 164 — живая свеча на границе бара, список монет, локальный Скринер

**Тег:** `metka-164`

## Что вошло

- **Живой график:** на закрытии бара новая свеча открывается по часам, а не
  ждёт следующий kline (~25 с паузы). WS больше не затирает новый бар
  confirm’ом старого; `series.update` при хвосте пустых баров падает в
  `setData`. То же на Скринере, Вотчлисте, Скрипте и зуме.
- **Список монет:** при загрузке остаётся сверху, без прыжка к BTC.
  Прокрутка к активному тикеру — только с клавиатуры.
- **RSI на старшем ТФ:** полный пересчёт на новой свече / confirm, не на
  каждом тике последней.
- **D/W:** следующий бар от последней свечи биржи (UTC-полночь / понедельник,
  не Unix-четверг).
- **Локальный сервер:** `/screener` отдаёт `screener.html` (как cleanUrls
  на Vercel).

Оригинал Pattern 1-2 не менялся.
