# Метка 91 — RSI delete, Script settings, hotkeys, no Screener Pattern (июль 2026)

**Тег:** `metka-91`

## Что вошло

### Терминал — удаление чертежа на RSI

- Корзина style bar и Delete/Backspace удаляют через RSI style-delegate,
  а не через `deleteSelected` основного графика.

### Скринер

- Убран показ Pattern 1-2 на виджетах и в zoom.
- Убран тумблер «Показывать Паттерн 1-2…» из Настройки → Системные.

### Скрипт — скан Pattern 1-2

- Перед парсингом снимок настроек индикатора с Терминала
  (`chart_indicators_v1` / `settings_pattern-12`), не жёсткие дефолты.
