## Что вошло

### Настройки → Системные (продолжение metka-93)

- Если **АлгоТрейдинг** выключен — в системном трее скрыт блок «Алго бот» (prefs зеркалятся в main).
- Если **Скрипт** выключен — на Терминале скрыт статус «Скрипт: …» в шапке.

### Настройки → Горячие клавиши

- Новый информационный раздел: список hotkeys по страницам (Скринер, Терминал, рисунки, торговля, Скрипт, АлгоТрейдинг).
- Без переключателей — только справка.
