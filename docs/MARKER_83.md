# Метка 83 — АлгоТрейдинг: панель Данные, курсор, ресайз графика (июль 2026)

**Тег:** `metka-83`

## Что вошло

### АлгоТрейдинг (desktop-only)

- Вертикаль курсора только на графике + RSI (не проходит через «Данные»).
- Плашка времени на нижней шкале RSI; плашка текущей цены на ценовой шкале.
- Панель «Данные»: ресайз вниз за разделитель (текущая высота = максимум).
- При ресайзе панели график расширяется; рисунки / паттерны / позиции едут
  вместе с графиком (как на Терминале).
