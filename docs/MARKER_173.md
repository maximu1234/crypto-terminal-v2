# Метка 173 — журнал комментариев в Дневнике, горизонталь на ценовой шкале

**Тег:** `metka-173`

## Что вошло

- **Дневник:** колонка «Коммент» в строке сделки (до 120 символов,
  сохранение как в Чеклисте). Журнал сделок с комментариями отдельно
  по Bybit / BingX: на desktop — файл в userData, на вебе — после
  загрузки файла в `localStorage`. При обновлении периода новые сделки
  дописываются, комментарии не затираются.
- **Скачать / Загрузить дневник:** меню «Скачать» → JSON (перенос) или
  Excel `.xls` (анализ); «Загрузить» полностью заменяет журнал текущей
  биржи после проверки `kind` / версии / `exchangeId`.
- **Терминал:** при наведении на ценовую шкалу остаётся горизонталь
  перекрестья (вертикаль гасится); «+» и зум шкалы без конфликта.

Оригинал индикатора Pattern 1-2 не менялся. Изоляция Bybit/BingX
сохранена (зеркальные правки `diary/page.js`).
