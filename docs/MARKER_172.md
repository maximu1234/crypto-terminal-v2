# Метка 172 — курсор на ручках рисования, фильтр объёма, дефолты Pattern 1-2-1-2-3

**Тег:** `metka-172`

## Что вошло

- **Ручки объектов рисования:** при перетаскивании опорной точки
  перекрестье садится в центр вершины (как у Position TP/SL) — линия,
  фибо, прямоугольник, канал, паттерн, FVP и остальные handle-drag.
- **Терминал, фильтр «Объём ≥»:** значение сохраняется в
  `coins_page_prefs_v1` и восстанавливается после ухода со страницы;
  при закрытии вкладки черновик в поле тоже пишется.
- **Рисунок Pattern 1-2-1-2-3:** заводские настройки как в панели —
  Wave выкл., Degree Submicro / Minuscule, dashed вкл., прозрачность
  100%, TP (1·2) вкл., TP (1·2·3) выкл., уровни
  `0.5 / 0.75 / 1 / 1.5 / 2 / 2.44 / 3`. **Apply Default** обновляет
  и открытую панель настроек.
- **Desktop Electron:** FOUC `html:not(.css-ready){visibility:hidden}`
  больше не считается пустым DOM и не уводит окно на стенку логина Vercel.

Оригинал индикатора Pattern 1-2 не менялся. Торговые модули Bybit/BingX
не затрагивались (только bump `?v=` у facades).
