# Метка 89 — Zoom hotkeys + log $ для Ст2/Ст3 + плашки позиции (июль 2026)

**Тег:** `metka-89`

## Что вошло

### Скринер / Скрипт — zoom по ПКМ

- Пока открыто большое окно графика: **Пробел / →** — следующий виджет,
  **←** — предыдущий (на краю страницы — соседняя страница).
- Клавиши **1–7** меняют ТФ внутри zoom, не у виджетов под окном.
- Окно закрыто — Пробел и 1–7 снова листают страницы / ТФ виджетов.

### АлгоТрейдинг — статистика Ст2/Ст3

- $ PnL по **лог-RR** к СЛ (как плашка позиции / Ст1), не линейная Δцена.
- В «Суммарную прибыль/убыток» только закрытые сделки с ненулевым итогом;
  открытые и «в ноль» не раздувают суммы.

### Чертёж позиции

- На плашках СЛ и ТП всегда **две цифры** после запятой (например `1,55$`).
