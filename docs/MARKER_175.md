# Метка 175 — DX-Ball в Терминале

**Тег:** `metka-175`

## Что вошло

- **Терминал:** кнопка DX-Ball над Чеклистом открывает игру на левой
  половине экрана (повторное нажатие закрывает). Полноэкранный по высоте
  canvas, управление мышью, без звука.
- **Endless:** 100 процедурных уровней; барьеры не запирают ломаемые
  блоки без пути к ним.
- Стрелки в меню игры не скроллят графики Терминала.

## Версии

- Web marker: `v0.175`
- Multichart desktop app: `v1.1.74`
