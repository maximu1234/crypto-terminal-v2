# Метка 199 — живые тики на Вотчлисте

**Тег:** `metka-199`  
**Откат chrome/chart:** `metka-181`

## Что вошло

- На сайте подписка на тики Bybit больше не рвётся, когда на Вотчлисте больше пяти виджетов. Биржа принимает не больше 10 тем за раз, а запрос уходил целиком и отклонялся. Теперь темы уходят пачками по 10, соединение держится пингом.

- Web: `v0.199`
- Desktop: `v1.1.85` (Mac + Windows)
