# Метка 166 — точные координаты рисунков, без лишних подсказок тикера

**Тег:** `metka-166`

## Что вошло

- **Координаты объектов рисования как в TradingView:** в настройках
  трендовой, горизонтальной, луча, стрелки, прямоугольника, фибы, канала
  и Long/Short можно задать цену и номер бара. Кисть, Эллиотт, текст и
  Fixed Volume Profile без этой вкладки.
- **Список тикеров и панель позиций:** убрана всплывающая подсказка,
  которая повторяла название тикера.
- **Desktop SOCKS:** Supabase и Railway worker идут в обход кафе-прокси,
  чтобы не ломались refresh сессии и постановка алертов.
- Правка синтаксиса `getStyleBarDelegate` (Терминал не открывался).

Оригинал Pattern 1-2 не менялся. Bybit/BingX — одинаковый UI-фикс
подсказки тикера, без торговой семантики.
