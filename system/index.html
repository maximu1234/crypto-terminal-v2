Очистка мусора алертов

Удаляет из Supabase зомби и сироты в price_alerts и всю историю price_alert_events для вашего аккаунта. Активные алерты из localStorage на этом устройстве сохраняются.

Требуется вход в аккаунт и (для истории событий) SQL-миграция migration-price-alert-events-delete-own.sql в Supabase.

Период проверки для worker

Подстраховочный reload активных алертов из Supabase (основной подхват идёт сразу после POST push/delete). По умолчанию: 30 минут.
