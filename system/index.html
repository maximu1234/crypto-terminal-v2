Очистка облака рисунков

На странице «Алерты» кнопка «Удалить все рисунки» очищает только ваш аккаунт на этом устройстве. Здесь — принудительная очистка таблицы user_drawings в Supabase для всех пользователей (например, после делистинга монеты с Bybit).

Требуется SYSTEM_ADMIN_EMAIL на Railway (тот же email, что для доступа к этой странице). Локальные рисунки в браузерах пользователей не затрагиваются — только облако.
